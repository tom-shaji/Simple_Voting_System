# Simple Voting System

A simple, beginner-friendly command-line voting application written in Python.

## Features
- List of 4 candidates to choose from.
- Users can cast a vote by entering their name and selecting a candidate.
- Validates voter names to prevent duplicate voting (one vote per person).
- Handles invalid inputs gracefully.
- Stores votes and candidates in a Python dictionary.
- Displays the current vote count and total number of voters.
- Displays the final voting results, including the winner or a tie.

## Requirements
- Python 3.x
- No external libraries required.

## How to Run
1. Open a terminal or command prompt.
2. Navigate to the project directory.
3. Run the following command:
   ```bash
   python main.py
   ```
4. Follow the on-screen menu instructions.

## Menu Options
1. **Cast Vote**: Enter your name and vote for a candidate.
2. **View Vote Count**: View how many votes each candidate currently has.
3. **View Voting Results**: View the final results and the winner(s).
4. **Exit**: Close the application.
